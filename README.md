# Poker Academy

A static site for learning Texas Hold'em poker — glossary, hand rankings, and an interactive practice trainer with AI opponent.

## Pages

- **Home** (`index.html`) — Hand rankings table, feature overview, animated hero
- **Glossary** (`glossary.html`) — 50+ terms across 6 categories, searchable with filters, game flow walkthrough, beginner tips
- **Play** (`play.html`) — Practice hands against an AI opponent with full hand evaluation engine

## Features

- Pure HTML/CSS/JS — no frameworks, no build step
- Full hand evaluation engine covering all 10 poker hand ranks
- AI opponent with pre-flop heuristics and post-flop hand strength decisions
- Chip tracking, win/loss stats, hand history log
- Responsive design with mobile hamburger nav
- Dark theme with felt-green poker table

## Deploy

Host on GitHub Pages or any static file server. No build step required — just serve the files.

## Files
